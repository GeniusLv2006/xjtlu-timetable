# Timetable Toolkit for XJTLU Students v0.3.1

v0.3.1 removes unused GeoIP metadata, keeps legal-notice hosting independent from application deployment, and updates a frontend build dependency.

## Highlights

- Removed city, network-organization, and GeoIP-provider fields from login and iCal access logs, administration views, user-visible history, and personal-data exports.
- Deleted historical values and the unused GeoIP cache during upgrade. The application does not contact a third-party GeoIP provider.
- Kept the country code, complete and prefixed IP addresses, user agent, timestamp, and account relationship used for security monitoring. The existing 30-day access-log retention period is unchanged.
- Pinned the build-time `nanoid` dependency to 3.3.17 to fix CVE-2026-67213. This dependency is not included in the PocketBase runtime image.

## Upgrade

This upgrade applies to supported `v0.3.0` installations. Back up PocketBase,
confirm that the current `IMAGE_TAG` is not already `v0.3.1`, then run:

```bash
./self-host.sh upgrade v0.3.1
```

Existing v0.3.0 installations must retain a valid `ACCOUNT_BLOCK_HMAC_KEYS` value. This release introduces no new environment variables.

## Rollback

The upgrade permanently deletes GeoIP metadata. For a manual rollback, restore the matching pre-upgrade database backup and previous immutable image together; reverting only the image cannot reconstruct the deleted data.
